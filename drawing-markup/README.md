# 三川工方｜繪圖與標記 V1.1

## 手機直接開啟

線上網址：https://heaven2935-code.github.io/sanchuan-cabinet-drawing/drawing-markup/

建議 iPhone Safari 使用。程式安裝在 GitHub Pages，主繪圖程式為 `index.html`。

## 核心操作

- **畫布優先**：左右側分別為可捲動工具列與畫布；右側屬性預設收合，點上方「屬性」叫出。橫向、直向都能使用。
- **線條**：直線、連續直線、虛線、箭頭、尺寸線。
- **圓弧**：圓形、半圓、1/4 圓、橢圓。橢圓可設定長軸及短軸全長、旋轉角度。
- **三角形**：一般、直角、等腰。直角三角形以 A 點固定為直角，等腰三角形的 AB、AC 為等長兩腰，可設定夾角與邊長。
- **正多角形**：五、六、七、八角形，提供邊數、等邊長、外接圓半徑、角度。
- **快速設定**：畫布上方的顏色、線寬、單位是常駐按鍵，點開後才顯示設定。
- **輔助線**：可開啟水平／垂直輔助線，並切換 10 mm 吸附及靠近 0°／45°／90° 等方向時的角度吸附。
- **精準微調**：先使用選取工具，點選形狀與端點；畫布上該端點附近出現方向鍵，中央點選可輪流切換 1、5、10、50 mm 位移步距。右側屬性可精確輸入座標、尺寸與造型參數。
- **文字與圖層**：可插入文字、調整字體及粗細，亦可選取圖層再次修改。
- **分享與檔案**：右上分享 PNG；可另存 PNG、SVG、JSON，JSON 可再次匯入編輯。

## 單位與精度

1 台尺 = 303 mm，公分 = 10 mm，程式的幾何尺寸以 mm 為內部座標。選擇單位只改變顯示數值，不更改原幾何尺寸。尺寸輸入與畫面吸附使用不同的精度機制，若要精準下料請再做施工尺寸核對。

## 注意事項

- GitHub Pages 更新會有發布時間差，若手機上顯示舊版，可重新整理或使用網址後加 `?v=1.1`。
- 直向畫面中右側屬性改為底部抽屜，橫向畫面中改為右側浮層。大部分時候都應保持收合以釋放畫布。
- 本機自動保存僅限於該瀏覽器資料，不能當作雲端備份。請定期匯出 JSON。
- 目前不包含幾何約束求解器、任意不規則多邊形任意點編輯、照片透視校正及正式工程拆料。
- 這版已通過 Chromium 模擬手機版操作和數值測試，iPhone Safari 實機操作仍須驗證。

## 程式與測試

`index.html` 為可獨立部署的程式。`test_v11.py` / `test_more.py` 為 Playwright 回歸測試（在具 Chromium 與 Playwright 的環境執行）。
