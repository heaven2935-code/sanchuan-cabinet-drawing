# 三川工方｜繪圖與標記 V1.10

手機入口：https://heaven2935-code.github.io/sanchuan-cabinet-drawing/drawing-markup/?v=1.10

`index.html` 是此獨立應用的來源與部署檔。本輪僅修改 `drawing-markup/`，沒有修改根目錄櫃體應用、mobile-source/、elevation/ 或獨立的 drawing-markup-master。

## 2026-10-27｜V1.10 圖層與選取整合（優先於下方 V1.9 紀錄）

- 「選取」會切回瀏覽並展開底部同一排圖層編號，不再開啟圖層浮窗。每個物件為一個圖層；照片存在時為第 1 層，其餘依目前堆疊順序編號。刪除、排序後重新依序編號，持久識別仍使用原有 id。
- 點 1、2、3… 選取整體，再點 A／B、圓心／半徑等控制點。編號多時僅編號區水平滑動；長按選取仍保留並同步編號。
- 選中後的編輯列位於畫布上方，占用獨立布局空間，不覆蓋圖紙。整體、移動、控制點、屬性、顯示／隱藏、複製、前後順序與刪除仍可用；屬性只在主動點選時開啟。
- 移除畫面上的加減縮放、縮放百分比、XY 座標、適屏按鍵及「更多」入口。維持雙指縮放平移。
- 瀏覽／編輯模式中，在空白處 320 ms 內連點兩次可適屏。拖曳、長按、雙指操作、物件點選不算空白雙擊；繪製模式保留原本兩點畫線，不觸發適屏。
- 重做在可用時顯示於頂部，不因移除「更多」而遺失。復原常駐底部。
- `test-v110.cjs` 是現行回歸測試；`test-v19.cjs` 保留為轉接入口。

## 2026-10-26｜V1.9 操作紀錄

- 預設為瀏覽／編輯：單指拖曳平移，長按約 400 ms 選取整個物件。開始移動超過 8 px 即取消長按，改為平移。
- 即使長按端點，第一次也只選整體；同一次觸碰不會接著移動物件。放開後，再點 A／B 或控制點調整。點線身回到整體，點空白解除選取。
- 選取後的「移動」明確啟用整體拖曳；圓形中心移動保持半徑。取消手勢恢復修改前快照。
- 底部「繪製」開啟單排圖形，選完收起。按「完成」回到瀏覽；沒有「無工具」狀態。移除原本逐層退出的返回、獨立選取／平移入口。
- 數值是繪製方式：先選圖形，再按「數值」。直線使用長度；圓形使用直徑；矩形使用寬／高；橢圓使用長半軸／短軸全長；圓弧與多角形使用半徑。其他形狀仍沿用既有建構參數，不能當成任意幾何約束工具。
- 必須先點畫布指定起點或圓心，才可確認。起點居中並明顯標示；旋鈕刻度固定，拖動外圈相對旋轉方向，按下時不跳角。接近每 45° 可吸附；數字角度不強制吸附。
- 坐標慣例延續舊資料：X 向右、Y 向下，0° 向右、90° 向下、180° 向左、270° 向上。
- 數值變更即時預覽，確認才建立；Enter 只結束輸入。連續線的終點成為下一起點；非線形確認後重新指定起點。取消丟棄草稿。復原會清除數值起點，避免沿用失效的終點。
- 雙指縮放與平移不新增線條；第二指加入時取消尚未完成的單指手勢。
- 設定回到獨立視窗。單位、格線、水平／垂直輔助線、角度／格點吸附、顏色及線寬都有用途與效果說明。關閉後釋放畫布。
- 保留原本 localStorage 圖檔鍵、圖層、照片、JSON、SVG／PNG 匯出，不搬動既有圖檔。矩形新增可選 `rectHeight`，沒有更改既有物件結構。

## 驗證

安裝 Node.js 與 Playwright 後執行：

```sh
node drawing-markup/test-v110.cjs
```

若 Playwright 不在預設模組路徑，可設定 `NODE_PATH`；自備 Chromium 可設定 `CHROMIUM_PATH`。

涵蓋：選取層級、長按防誤移、端點隔離與復原、數值旋鈕、長度／直徑／矩形尺寸、無效數值、取消、雙指縮放平移與防誤畫、存檔重載、乾淨 SVG 匯出、設定視窗與直橫向畫面。

已做 Chromium 390×844 與 844×390 模擬檢查。iPhone Safari 真機手感、軟鍵盤及分享存相簿仍需實測；不將模擬檢查當成真機驗收。

## 儲存與尺寸

內部以 mm 儲存。1 台尺＝303 mm。變更顯示單位不改幾何尺寸。照片尚無比例校準，不把照片像素直接當成施工尺寸。本機保存僅限目前瀏覽器，重要圖面請匯出 JSON 備份。
