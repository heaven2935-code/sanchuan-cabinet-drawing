# 三川工方｜櫃體立面繪圖 V1.1

供手機橫向操作的櫃體立面繪圖網頁應用。本專案與 `EMS-LINE` 工程管理系統分開，不修改其資料。

## 網站啟用

預定的 GitHub Pages 網址（**啟用 GitHub Pages 前無法訪問**）：
https://heaven2935-code.github.io/sanchuan-cabinet-drawing/

首次啟用：開啟 [Settings → Pages](https://github.com/heaven2935-code/sanchuan-cabinet-drawing/settings/pages)，於 **Build and deployment** 的 Source 選擇 **Deploy from a branch**，Branch 選擇 `main` 與 `/(root)`，點選 Save。待 GitHub 顯示成功發布後，從 Safari 開啟上方網址。

## 操作

- iPhone 建議橫向操作，需使用 Safari 等支援 JavaScript 的瀏覽器，不要透過附件預覽畫圖。
- 選直線／矩形／圓形／尺寸工具後，可在畫布單指按住拖曳，也可分兩次點選起點及終點。
- 遠端觸控板控制十字游標，搭配 1、5、10 mm 移動與 X/Y 座標輸入。
- 分格、外／內視圖、復原／重做、JSON／SVG／PNG 匯出。
- 自動暫存只保留在當前瀏覽器；重要圖面務必匯出 JSON 另行備份。

## 注意

- V1.1 是概念／立面繪圖程式，不是完整 CAD 或可直接下料的裁板軟體。
- 18 mm 板厚的櫃內示意未扣除門縫、封邊、背板與五金淨距。
- 已有模擬瀏覽器測試，但尚未經使用者 iPhone Safari 實際測試確認。
- 此公開儲存庫適合存放程式碼，不應直接加入客戶私有照片、個資與工程檔案。
