# 語音後端：本人試用版

此程式尚未部署，沒有 API 金鑰或實際音訊驗收。主網頁可獨立使用文字口令。

## 部署設定

獨立建立 Node 22 以上服務，來源為此儲存庫的 `mobile-source/voice-server`。不使用、不修改 EMS-LINE。無第三方 npm 相依套件；啟動命令 `node server.mjs`。可用本目錄 `render.yaml` 作為 Render Blueprint（建立時指定本檔路徑）。

後端秘密環境變數：

- `OPENAI_API_KEY`：擁有者在 OpenAI API 平台建立的專案金鑰，只填服務商的秘密設定，不貼對話、不寫 GitHub、不填前端。
- `VOICE_OWNER_TOKEN`：至少32字元高熵隨機通行碼，與 API 金鑰不同。Blueprint 可產生隨機值；取出後在自己手機輸入。持有者可使用，這不是個人身分登入；第一版不對外分享。
- `VOICE_ALLOWED_ORIGIN`：`https://heaven2935-code.github.io`（Origin 不含路徑；同網域其他 Pages 專案仍須通行碼）。
- `VOICE_HOURLY_LIMIT`：每個程序每小時最多120次辨識嘗試，可調低不能調高。失敗嘗試也計數；同時僅一請求。重啟會重置，**不是帳戶總費用硬上限**。試用僅一執行個體；上線多人服務前改持久化配額與身分驗證。
- `PORT`：由主機提供，預設8787。

部署後 `/health` 回傳 `ready:true` 只代表秘密設定存在，不代表金鑰有效、帳戶有額度或模型可用。真實 API 需付費帳戶另行測試；程式不自動切換供應商。

## 手機試用

1. 主網址「＋ → 口令丈量」設定起點及線型，按開始丈量。
2. 展開「語音試用設定」，填後端 HTTPS 網址與本人試用通行碼。API 金鑰不可填在此處。
3. 連耳機，閱讀音訊傳輸說明並勾同意；啟動語音及允許麥克風。
4. 一次一口令，停頓約0.9秒，等回讀完再說確認。每段不必重新啟動。例：往上1200 → 回讀 → 確認 → 回讀 → 往左1800。
5.「暫停」暫停繪圖，仍收音聽取「繼續」；要完全關麥請按關閉麥克風或結束。鎖屏、背景、切圖及系統中斷會關閉收音，回來須主動重新啟動，終點保留。

## 誠實界線與準確率

- 目前採持續前景收音、端上依音量與停頓分句，每句完整無損 WAV 送 `/v1/audio/transcriptions` 的 `gpt-transcribe`。**不是 WebSocket 即時逐字串流**，只有完整辨識結果後預覽。選擇完整短句先驗證方向與數字，延遲待實測。
- 音量門檻是初步分段，不是工地語音／噪音分類模型。預留250ms開頭、至少180ms有聲、900ms停頓、最長8秒；長句或持續噪音拒絕而非截成錯誤尺寸。
- 麥克風請求單聲道、回音消除與噪音抑制，瀏覽器可能忽略；實際裝置／藍牙路由由作業系統決定。沒有宣稱耳機一定比手機準。
- 回讀使用系統 zh-TW 語音；回讀期間丟棄輸入，結束後留450ms尾音緩衝。回讀失敗不允許語音確認。語音同句「往上1200確認」只預覽，不落筆；文字模式維持原功能。
- 連線失敗不自動重送音訊、不在背景恢復、不重畫、不丟終點。重新啟動會清除未確認草稿並要求重說。
- 音訊只存在記憶體，不寫本機／伺服器檔案，也不記錄音訊／逐字稿；上游依供應商政策處理。通行碼只在本頁記憶體，重載需重填。
- 模擬測試不等於真實辨識準確率、手機觸控或耳機驗收。完整驗收依 `../VOICE_ACCURACY.md`，待設定後端及帳戶後由使用者實測。

官方介面來源（2026-10-14查核）：https://developers.openai.com/api/docs/guides/speech-to-text 。`gpt-transcribe` 使用 `languages[]`，不可同送舊 `language`。不使用數字範例提示，以免模型補出不存在的數字。
