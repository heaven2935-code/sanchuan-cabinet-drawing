# 程式結構

| 檔案 | 功能 |
| --- | --- |
| legacy-source.html | 原有櫃體資料模型、幾何繪製、數值限制、存檔與匯出引擎 |
| mobile-ui.js | 點選、平移、縮放、操作預覽、設定表單、情境選單與圖面管理 |
| mobile-rulers.js | 按需顯示的 X／Y 尺軌、拖動標示、全畫面對準線與縮放同步 |
| mobile-ui.css | 手機全畫面排版、安全區、操作列與底部設定面板 |
| ui-policy.js | 判斷選到的項目可顯示哪些操作；精準分隔數值限制 |
| scripts/build.py | 合併原引擎與手機介面，產生獨立 HTML、Logo 與主畫面設定 |
| tests/verify.cjs | 幾何、尺寸、透視、匯出與情境選單驗證 |
| dist/ | 可直接部署的靜態網站 |

操作狀態依序為：看圖 → 選取 → 編輯／預覽 → 完成後回到看圖。

繪圖與計算使用原引擎。新表單透過既有尺寸調整方法修改資料，完整表單套用合併為一個復原步驟。

新增功能前先核對：是否真的需要常駐按鍵、對哪些選取項目有效、完成或取消後是否收起，以及是否保留復原紀錄。

尺軌與 SVG 共用 `viewportMap` 座標轉換。X 是距櫃體左側，Y 是離櫃體底部的高度；圖面 y 座標向下，因此 Y = 總高 − 圖面 y。尺軌只修改操作預覽，按「確定」才提交分隔線；取消還原標註移動。


## 2026-10-14 圖面顯示設定

正式入口為 GitHub 根目錄，elevation/ 保留不動。display-style.js 管理裝置顯示偏好、格線與中點幾何；scripts/build.py 將偏好注入原引擎與匯出流程。mobile-ui.js 的 mDisplayOpen 提供設定與儲存，mobile-rulers.js 支援左右尺軌。
